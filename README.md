# DisenchantValue

WoW Forever (interface 16001). Needs Auctionator.

- Item tooltips show the estimated auction value of disenchanting the item (Classic disenchant odds from classic-db × Auctionator prices). Hold Shift for the breakdown.
- Logs every disenchant on every character into one account-wide database (`DisenchantValueDB`) and shows your own results on tooltips, per item and per item-level bracket.
- `/dv` opens the window (overview, recent disenchants, options; also under Settings > AddOns). Its chat commands follow the same pattern as every EverlookDB addon: `/dv status` (version, totals, whether Auctionator is there), `/dv recent` (last 10), `/dv breakdown always` or `/dv set breakdown always` (change a setting; `/dv get` lists them), `/dv announce off` (no chat line after each disenchant), `/dv search <words>` (the window with its search box filled), `/dv help` (or `?`) lists everything. A mistyped command suggests the nearest one. The old `/dv summary` and `/dv quiet` still work.

## Credits

The disenchant odds in `Data/` are generated by `tools/gen_data.py` from [classic-db](https://github.com/cmangos/classic-db), the CMaNGOS community's Classic 1.12 world database (GPL-3.0): its `disenchant_loot_template` and the item levels of `item_template`. WoW Forever can differ; your own logged disenchants show next to the estimate. Prices come from your [Auctionator](https://www.curseforge.com/wow/addons/auctionator) scans at run time.
